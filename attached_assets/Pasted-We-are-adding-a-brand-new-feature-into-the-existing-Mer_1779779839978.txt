====================================================
FEATURE: PRODUCT SETUP WIZARD
====================================================

We are replacing an old Excel-based product setup process with a guided, dynamic wizard experience.

The goal is:
- Make product creation simple
- Dynamically show ONLY relevant fields
- Enforce mandatory data
- Reduce user overwhelm
- Support retail merchandising workflows
- Support future governance/validation rules

This is NOT a simple static form.

This is a:
- dynamic wizard
- metadata-driven form system
- hierarchy-driven validation flow

====================================================
OVERALL UX DIRECTION
====================================================

The experience should feel modern, premium, clean, and guided.

Design inspiration:
- Shopify product creation
- Modern PIM systems
- Airtable-like dynamic forms
- Enterprise SaaS onboarding flows

VISUAL STYLE:
- Frosted glass / soft translucent cards
- Subtle gradients
- Soft shadows
- Minimal but information-dense
- Strong spacing hierarchy
- Smooth transitions/animations
- Modern typography
- Contextual validation states
- Elegant progressive disclosure

DO NOT:
- Build giant ERP tables
- Show all fields at once
- Create spreadsheet-style UX
- Overwhelm users
