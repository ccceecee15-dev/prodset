Create a completely new page called "Planner Report V2".

IMPORTANT

- This is a proof-of-concept replacement for the current Planner Report.
- DO NOT modify the existing Planner Report screen in any way.
- Keep both reports available in the application.
- Reuse the application's existing design language, typography, spacing, components, colours and navigation.
- The new page should feel like a natural part of the existing application.

=========================================================
DESIGN GOAL
=========================================================

Do NOT recreate the Excel sheet.

Do NOT build a BI dashboard full of filters.

Instead, build a modern enterprise merchandising analysis workspace.

The Excel report is really an interactive Pivot Report where the planner changes HOW they view the data rather than filtering it.

The UI should preserve every business capability while making the experience significantly easier.

=========================================================
SUCCESS CRITERIA
=========================================================

When the client compares this screen with the Excel report they should immediately recognise that every analytical capability has been retained.

However, they should also clearly see that this is a modern retail planning application rather than a spreadsheet.

The emphasis should be on discoverability, scalability and ease of analysis while preserving the exact business logic of the original Planner Report.
